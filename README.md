# Cloud Student Tasks

## Цель проекта
Простое веб-приложение для управления учебными заданиями студентов.

## Использованные технологии
- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## Возможности
- Добавление новых заданий
- Отметка выполненных заданий
- Удаление заданий
- Подсчёт общего количества заданий
- Подсчёт выполненных заданий

## Как запустить
Откройте файл index.html в браузере.

## Опубликованный сайт
Вставьте сюда ссылку GitHub Pages.
